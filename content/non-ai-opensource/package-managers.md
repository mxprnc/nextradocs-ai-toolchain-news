## NVM
- **GitHub:** https://github.com/nvm-sh/nvm
- **설명:** Node.js 버전을 설치하고 관리할 수 있는 버전 관리자입니다.

여러 종류의 node 버전을 선택해서 사용할수도 있고, 프로젝트 별 사용할 nvm 버전을 `.nvmrc` 라는 파일에 명시해서 프로젝트에서 사용할 node 버전을 고정할수도 있습니다. 2026/11/18일 Github Opensource 랭킹에서 7위를 했는데, 최근 보안 업데이트가 있어서 보안 업데이트를 위해 랭킹에 진입한것으로 보입니다. 보안 업데이트를 오랫동안 받지 않으신 분들은 업데이트 받으시길 바랍니다.
