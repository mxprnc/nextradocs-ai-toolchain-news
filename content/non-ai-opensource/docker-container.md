# Docker Container 편의성 도구

## Arcane (2:32)

- **GitHub:** https://github.com/getarcaneapp/arcane
- **설명:** Docker 컨테이너를 웹 화면에서 클릭만으로 쉽게 관리할 수 있도록 지원하는 도구입니다.<br/>

도커를 터미널 명령 대신 웹 화면에서 클릭만으로 관리할수 있도록 해주는 무료도구 입니다. 컨테이너를 켜고 끄는 것부터 로그확인, 설정 파일 수정까지 클릭으로 할수 있어서 명령어를 외우지 않아도 됩니다.<br/>

대시보드에서는 CPU,메모리 사용량을 실시간 그래프로 보여주고, 쓰고 있는 이미지에 알려진 보안 취약점이 있는지도 바로 검사해줍니다.<br/>

이 대시보드는 2026/11/14일에 나온 3.0 버전에서 새로 만든 기능입니다. 서버가 여러대라면 각 서버의 도커를 대시보드에서 모아서 관리할 수도 있습니다.<br/>
