# 코딩 지원 도구

## DietrichGebert/ponytail
https://github.com/DietrichGebert/ponytail

AI가 쓸데없이 코드를 길게 짜는 것을 막는 스킬
새로 시작하기 전에 꼭 필요한지, 이미 있는 코드나 기본 기능으로 되는지부터 따지게 해서, 회사에서 가장 게으른 시니어 개발자처럼 일하게 만듭니다.
만든사람 테스트에서는 코드가 53%, 비용이 26% 줄었습니다.


## anomalyco/opencode
https://github.com/anomalyco/opencode

클로드코드같은 코딩 에이전트를 오픈소스로 만든것
터미널이나 데스크톱 앱에서 말로 시키면 코드를 찾아 고쳐주고, 탭 키 하나로 바로 고치는 모드와 손대지 않고 분석만 하는 계획모드를 오갑니다.


## headroomlabs-ai/headroom
https://github.com/headroomlabs-ai/headroom

AI 코딩 에이전트가 읽는 로그, 파일, 도구 결과를 AI에 보내기 전에 압축해주는 도구

같은 일을 시켜도 토큰이 확 줄어서 사용량 한도와 비용을 아낄 수 있는데 예시에서는 10000개 넘던 토큰이 1200개로 줄고도 찾아낸 오류는 같았습니다.
