# AI 개발 도구 GitHub 트렌딩 순위 (2026.11.18, solostack)
https://www.youtube.com/watch?v=z6EDNyCYkh0


## 1위. GoogleChrome/modern-web-guidance-src

코딩 에이전트가 오래된 방식 대신 최신 HTML·CSS·브라우저 API를 사용하도록 돕는 지침 스킬 및 CLI입니다. 검색은 로컬에서 수행하며, 262개의 웹 기능과 각 기능의 브라우저 지원 정보를 제공합니다.

- **주요 업데이트**
  - 11/10 Chrome 공식 블로그에서 1.0 정식판 발표
  - Firefox·Edge 팀도 함께 관리
  - 1.0에 기존 코드의 오래된 패턴을 탐지하는 `legacy-scan` 추가
  - Chrome 팀 자체 평가에서 Claude Code 과제 통과율 57% → 88%
  - 발표 후 일주일간 npm 다운로드 약 2.5배 증가
- **참고 사항**
  - 트렌딩에 오른 저장소는 원본(`-src`)이며, 실제 설치되는 배포본은 `GoogleChrome/modern-web-guidance`입니다.
  - 사용 통계 기본 활성화(에이전트가 생성한 검색어가 Google로 전송됨)

## 2위. backnotprop/plannotator

에이전트가 작성한 계획·문서·코드 변경을 브라우저에서 줄 단위 댓글로 검토하고, 피드백을 한 번에 에이전트에게 전달하는 도구입니다. 여러 에이전트의 검토 요청을 모아 관리하는 받은편지함(Inbox) 기능도 제공합니다.

- **주요 업데이트**
  - 이번 주 릴리스 7건
  - Inbox 에이전트의 Windows 동작 개선
  - T3 Code 연결
- **참고 사항**
  - 작은 공유 링크는 암호화 없이 주소에 포함됩니다.
  - 익명 사용 통계 기본 활성화

## 3위. meta/astryx

Meta가 사내에서 8년간 사용해 온 디자인 시스템입니다. 150개 이상의 React 컴포넌트, 7종 테마, 다크 모드를 지원합니다.

CLI를 통해 컴포넌트 문서를 검색하고 템플릿을 추천하여, 코딩 에이전트가 존재하지 않는 컴포넌트를 임의로 만들어 내지 않도록 설계되었습니다.

- **주요 업데이트**
  - 이번 주 릴리스 4건
  - 테이블 가상화 및 모바일 동작 개선
  - 주간 증가량 기준 게재된 14개 프로젝트 중 최대
- **참고 사항**
  - Beta(0.7.x) 단계이므로 버전 고정을 권장합니다.

## 4위. we-promise/sure

개인 가계부 웹 애플리케이션입니다. 개발이 중단된 Maybe Finance의 커뮤니티 포크로, 자체 호스팅과 MCP 연결을 지원합니다.

- **주요 업데이트**
  - 이번 주 알파 업데이트
  - 대출 원금·이자 분리
  - 감사 기록 기능 추가
  - 저장 데이터 암호화 강화
- **참고 사항**
  - AGPL-3.0 라이선스
  - 익명 사용 통계 하루 한 번 전송(비활성화 가능)
  - 은행 연동은 Plaid 등 해외 집계 서비스를 경유합니다.

## 5위. ZhuLinsen/daily_stock_analysis

관심 종목의 시세와 뉴스를 수집하고, LLM을 이용해 분석 보고서를 작성한 뒤 메신저나 이메일로 전송하는 시스템입니다. GitHub Actions를 통한 자동 실행도 가능합니다.

- **주요 업데이트**
  - v3.35.0 (11/16)
  - 대만 시장 복기 기능 추가
- **참고 사항**
  - 최소 1개의 LLM API 키가 필요하며 모델 사용 요금은 별도입니다.
  - 개발자가 밝힌 대로 학습·연구용이며 투자 조언이 아닙니다.

## 6위. anthropics/skills

Anthropic에서 공개한 공식 예제 스킬 모음입니다.

- **주요 업데이트**
  - 이번 주 문서 관련 스킬 2회 수정
  - PPTX: 테마 → 레이아웃 → 자리 표시 칸 순서로 구성하는 구조화된 덱 생성 방식
  - XLSX: 사본에서 계산한 뒤 값만 원본에 반영하여 외부 링크 보존
  - 문서를 PDF·이미지로 변환할 때 문서 외부 파일 링크부터 제거하도록 개선

## 7위. elementalsouls/Claude-BugHunter

버그 바운티 및 외부 모의 침투 테스트를 위한 스킬 모음입니다.

83개 스킬과 공개 보고서 681건에서 추출한 패턴, 제출 전 7문항 점검 절차를 제공합니다.

- **주요 업데이트**
  - 이번 주 수정 PR 약 60건
  - 자동 점검에서 쓰기 요청은 건너뛰도록 변경
  - 리다이렉트는 따라가지 않고 기록만 하도록 변경
- **참고 사항**
  - 본인 소유이거나 서면으로 허가받은 자산에만 사용해야 합니다.
  - 스킬 내용은 CC BY 4.0 라이선스이며 출처 표기가 필요합니다.

## 8위. alibaba/open-code-review

코드 변경 사항에 줄 단위 리뷰 댓글을 남기는 CLI입니다.

파일 선택과 댓글 위치 지정은 정해진 코드가 담당하고, 문맥 판단만 에이전트가 수행하는 구조입니다.

- **주요 업데이트**
  - 9월 말 이후 릴리스 16건
  - 10월 ChatGPT 요금제 로그인 미리보기 추가
  - 이번 주 GitHub Copilot CLI 연동
  - `--tools` 옵션 제거
- **참고 사항**
  - ChatGPT 로그인은 개인 및 본인 컴퓨터 사용을 전제로 합니다.
  - 공용 CI 환경에서 개인 계정을 사용하지 않아야 합니다.

## 9위. vercel-labs/agent-browser

에이전트가 셸 명령을 통해 브라우저를 제어할 수 있도록 지원하는 CLI입니다.

- **주요 업데이트**
  - v0.43.0 (11/13 KST)
  - Modern Web Guidance 스킬 추가
  - 지침에 따라 만든 페이지의 화면 밀림, 움직임 감소, 색 테마, 대화상자 포커스 등을 실제 브라우저에서 확인하고 근거와 함께 보고
  - 이름이 없는 아이콘 버튼에 대한 힌트 추가
- **참고 사항**
  - 기본 설정에서는 페이지 이동과 동작에 제한이 없습니다.

## 10위. ChromeDevTools/chrome-devtools-mcp

코딩 에이전트가 실제 Chrome을 열고 조작하면서 성능·네트워크·콘솔·메모리 등을 Chrome DevTools 기능 그대로 확인할 수 있도록 지원하는 Google 공식 도구입니다.

- **주요 업데이트**
  - v1.13.0 (11/11)
  - 네트워크 응답을 로컬 파일로 대체하는 네트워크 목(Mock) 기능 추가(기본 비활성화, `--categoryNetworkMocks` 옵션)
  - 코드 수정 없이 로그를 남기는 Logpoint 지원
- **참고 사항**
  - 사용 통계 기본 활성화
  - 성능 측정 시 페이지 주소가 Google(CrUX)로 전송될 수 있습니다.
