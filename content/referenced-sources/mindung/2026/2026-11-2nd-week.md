# GitHub Trending 프로젝트 순위
영상: https://www.youtube.com/watch?v=wD_KuqThn1g<br/>

참고: 이번 영상에는 2위가 없어요.<br/>
<br/>

## 1위. Claude-BugHunter (0:20)

- **GitHub:** https://github.com/elementalsouls/Claude-BugHunter
- **설명:** Claude Code를 보안 연구자처럼 활용하여 버그 바운티를 수행할 수 있게 해주는 도구입니다.

## 3위. CLI-Anything (1:13)

- **GitHub:** https://github.com/HKUDS/CLI-Anything
- **설명:** 마우스로만 제어하던 프로그램을 터미널 명령어 기반으로 조종할 수 있게 해주는 도구입니다.

## 4위. Last30days (2:03)

- **GitHub:** https://github.com/mvanhorn/last30days
- **설명:** 다양한 커뮤니티의 여론을 분석하여 특정 주제에 대한 요약 정보를 제공합니다.

## 5위. Arcane (2:32)

- **GitHub:** https://github.com/getarcaneapp/arcane
- **설명:** Docker 컨테이너를 웹 화면에서 클릭만으로 쉽게 관리할 수 있도록 지원하는 도구입니다.

## 6위. SkillEvaluator (3:03)

- **GitHub:** https://github.com/NVIDIA/SkillEvaluator
- **설명:** NVIDIA에서 만든 AI 에이전트용 스킬 성능 평가 도구입니다.

## 7위. NVM

- **GitHub:** https://github.com/nvm-sh/nvm
- **설명:** Node.js 버전을 설치하고 관리할 수 있는 버전 관리자입니다.

## 8위. UV (4:24)

- **GitHub:** https://github.com/astral-sh/uv
- **설명:** 기존 pip 대비 빠른 속도를 제공하는 차세대 파이썬 패키지 관리자입니다.

## 9위. Paper-Orchestra (5:02)

- **GitHub:** https://github.com/google-research/paper-orchestra
- **설명:** 5개의 AI 에이전트가 협업하여 논문을 작성하도록 돕는 멀티 에이전트 프레임워크입니다.

## 10위. Stitch-Skills (5:40)

- **GitHub:** https://github.com/google-labs-code/stitch-skills
- **설명:** 디자인 도구 Stitch를 코딩 에이전트와 연동하여 화면을 생성할 수 있도록 지원하는 스킬 모음입니다.

## 11위. Svelte

- **GitHub:** https://github.com/sveltejs/svelte
- **설명:** 컴파일 기반의 웹 애플리케이션 프레임워크입니다.

## 13위. Appwrite (6:50)

- **GitHub:** https://github.com/appwrite/appwrite
- **설명:** 로그인, 데이터베이스 등 백엔드 기능을 통합 제공하는 오픈소스 백엔드 플랫폼입니다.

## 14위. OpenVINO

- **GitHub:** https://github.com/openvinotoolkit/openvino
- **설명:** Intel에서 개발한 오픈소스 AI 추론 및 최적화 툴킷입니다.

## 15위. Superpowers

- **GitHub:** https://github.com/obra/superpowers
- **설명:** AI 코딩 에이전트가 체계적인 개발 절차와 검증된 워크플로를 따르도록 지원하는 스킬 프레임워크입니다.

## 16위. ECC (8:02)

- **GitHub:** https://github.com/affaan-m/everything-claude-code
- **설명:** 72개의 에이전트와 수백 개의 스킬이 포함된 체계적인 AI 코딩 환경 설정 도구입니다.

## 19위. Solid

- **GitHub:** https://github.com/solidjs/solid
- **설명:** 반응성과 성능에 초점을 맞춘 JavaScript UI 라이브러리입니다.

## 20위. Awesome-MCP-Servers

- **GitHub:** https://github.com/punkpeye/awesome-mcp-servers
- **설명:** 다양한 MCP(Model Context Protocol) 서버 구현체와 관련 프로젝트를 모아 놓은 큐레이션 저장소입니다.

---

**정리 참고 사항**
- 총 16개 프로젝트입니다.
- 원문에서 언급되지 않은 순위(2위, 12위, 17위, 18위)는 생략했습니다.
- 영상 타임스탬프가 제공되지 않은 프로젝트는 순위만 표기했습니다.
- Last30days와 Stitch-Skills는 저장소 주소를 사용하기 전에 실제 프로젝트와 일치하는지 확인하는 것이 좋습니다.
