# 온디바이스 지원 도구

## OpenVINO
- **GitHub:** https://github.com/openvinotoolkit/openvino
- **설명:** Intel에서 개발한 오픈소스 AI 추론 및 최적화 툴킷입니다.

다 만든 AI 모델을 일반 PC 내에서 CPU, 내장그래픽, NPU 에서도 돌아갈 수 있도록 다듬어서 최적화를 해주는 도구입니다. 파이토치, 텐서플로, ONNX로 만든 모델을 그대로 불러올 수 있고 pip 한줄로 설치해서 바로 써 볼수 있습니다.<br/>

`pip install openvino` 와 같은 명령어 한줄로 설치해서 바로 써볼 수 있습니다.<br/>
