# 연구 지원 도구

## google-research/paper-orchestra
- **GitHub:** https://github.com/google-research/paper-orchestra
- **설명:** 5개의 AI 에이전트가 협업하여 논문을 작성하도록 돕는 멀티 에이전트 프레임워크입니다.

구글 리서치가 공개한 논문 작성 에이전트입니다.<br/>

아이디어 메모와 실험 기록을 넣으면 AI 에이전트 다섯이 일을 나눠 맡습니다. 목차, 그래프, 관련 논문과 인용확인, 본문작성을 하나씩 맡고, 나머지 1개의 에이전트는 심사위원처럼 원고의 허점을 짚어 고칩니다. 이렇게 40분 쯤 지나면 학회 논문 형식의 원고 초안이 나옵니다. 다만 구글 공식 판은 Open AI, Gemini API 키가 있어야 돌아갑니다.<br/>

이 것을 어떤 한 개발자가 클로드코드,커서에서 쓰는 스킬로 옮겨둔 버전은 API 키 없이도 쓸수 있습니다.<br/>

API 키 없이 쓰는 스킬 버전: https://github.com/Ar9av/PaperOrchestra
