## we-promise/sure
개인 가계부 웹 애플리케이션입니다. 개발이 중단된 Maybe Finance의 커뮤니티 포크로, 자체 호스팅과 MCP 연결을 지원합니다.

- **주요 업데이트**
  - 이번 주 알파 업데이트
  - 대출 원금·이자 분리
  - 감사 기록 기능 추가
  - 저장 데이터 암호화 강화
- **참고 사항**
  - AGPL-3.0 라이선스
  - 익명 사용 통계 하루 한 번 전송(비활성화 가능)
  - 은행 연동은 Plaid 등 해외 집계 서비스를 경유합니다.

## ZhuLinsen/daily_stock_analysis
관심 종목의 시세와 뉴스를 수집하고, LLM을 이용해 분석 보고서를 작성한 뒤 메신저나 이메일로 전송하는 시스템입니다. GitHub Actions를 통한 자동 실행도 가능합니다.

- **주요 업데이트**
  - v3.35.0 (2026/11/16)
  - 대만 시장 복기 기능 추가
- **참고 사항**
  - 최소 1개의 LLM API 키가 필요하며 모델 사용 요금은 별도입니다.
  - 개발자가 밝힌 대로 학습·연구용이며 투자 조언이 아닙니다.

다들 직접 만든 '데일리 증권 리포트 봇' 같은걸 가진 분들이 많으실 것 같습니다. 굳이 위의 리포지터리를 그대로 쓸 필요까진 없는데, 어떻게 되어 있는지 내용에 참고할 부분은 있을지, 내 봇에 추가할만한것은 있을지 등과 같은 면을 검토하는 측면에서는 나쁠 것이 없어보입니다.
